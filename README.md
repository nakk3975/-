# CertificateStudy

정보처리산업기사 시험을 준비하면서 학습한 내용을 과목별로 정리한 저장소입니다.

## 정리 내용

`정보처리산업기사` 디렉터리를 기준으로 주요 학습 내용을 Markdown 문서로 정리했습니다.

- 응용 SW 기초 기술 활용
- 화면 구현 및 UI 관련 내용
- 프로그래밍 언어 활용
- 데이터베이스 및 SQL 관련 내용
- 애플리케이션 테스트/운영 관련 내용
- 애플리케이션 배포

## 저장소 목적

시험 대비 과정에서 학습한 개념을 다시 찾아보기 쉽도록 개인 노트 형태로 정리하고, 반복 학습할 수 있도록 관리하는 것이 목적입니다.

## 문서 형식

학습 자료는 주로 Markdown(`.md`)으로 작성되어 있어 GitHub에서 바로 열람할 수 있습니다.

> 이 저장소는 개인 학습 기록이며, 시험 범위나 출제 기준은 시점에 따라 달라질 수 있습니다.
